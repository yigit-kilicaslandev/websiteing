## [Come check it out!](https://yigitkilicaslan.com)

## What's on here?

Projects I've made, robot and coding competitions I've joined, photos from places I've visited, and blog posts about stuff I'm trying.

## What's it made with?

Astro puts the website together. React and TypeScript help with interactive parts, CSS and Tailwind make it look really good, and MDX is for blog posts in the blog section.
