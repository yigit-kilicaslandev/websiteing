# How I made my website

Hi, I'm Yiğit. I'm 11 and this is my website. I started it when I was 10, in 2026. I didn't have loads of projects to put on it, but I still wanted somewhere to share the things I make.

The website itself counts as a project too, so that helped.

## Where I started

I used a template called [Starfolio](https://github.com/webrating/starfolio). I forked it on GitHub, which means I made my own copy that I could change.

So I didn't write everything from zero. The layout was already there. I changed it to have my information, schools, projects and robot competitions instead of the example stuff.

## Making it mine

Most of my information is in a file called `src/data/resume.tsx`. That's where I can add a project or change my bio without searching through every page.

I added my Lego sumo robot and this website to the projects. I also added a travel photo section and icons for the languages and tools I use. Picking the icons was a small thing, but I like seeing them all together.

The site uses Astro, TypeScript and Tailwind CSS. These blog posts are MDX files. For this post I'm mostly just writing text in one of those files.

## Things broke too

I had to fix the X icon because the one I tried to use wasn't exported by the icon library.

Then there were the photos. Two of the travel photos were bigger than Cloudflare's 25 MiB file limit, so the build failed. They were just pictures of Dubai and Santorini, but they were huge files. They're replaced with smaller ones now.

I also added photo credits. The travel pictures aren't photos I took myself, and some of their licenses require credit to the photographer.

If you look at my older commits, some of the messages don't explain much. A message like "new update" isn't very helpful when I'm trying to find what I changed later.

## What I want to add

More projects, mostly. I'd like to have more robot and coding stuff to show here, and write about it when I do.

For now, you can look around the site or check the code on [GitHub](https://github.com/yigit-kilicaslandev/websiteing). It's still something I'm working on.
