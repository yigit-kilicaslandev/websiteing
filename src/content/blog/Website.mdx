# How I made my website

I'm 11 and I wanted my own website to put my projects on. I started it in 2026 when I was 10. There weren't many projects to add yet, but now the website is one of them lol.

I didn't make the whole thing from scratch. I forked [Starfolio](https://github.com/webrating/starfolio) on GitHub and started changing the example stuff to my own information. The design was already there, which helped a lot.

## What I changed

There's a file called `resume.tsx` with my name, schools, projects and other information in it. Most of my changes started there. I added my Lego sumo robot, the competitions I've joined and this website.

Then I added travel pictures and the icons in the skills section. I ended up removing some skills too. Just because the website uses React and TypeScript doesn't mean I know them well enough to put them on my list.

I use AI to help with the code. I'm still learning, and being able to change my information in a file isn't the same as knowing how every part of the website works.

## A few things went wrong

The X icon broke because the icon library didn't export the one we were trying to use. The dark mode button also got stuck showing the sun, even in light mode. The moon icon was there, just hidden all the time.

The Dubai and Santorini photos were too big for Cloudflare. It has a 25 MiB limit for each file, and both were over it, so the build failed. We replaced them with smaller photos. I wouldn't have guessed two pictures could stop the whole build.

The travel photos are from other photographers, so there's a credits section under the gallery now. Some of the licenses require it.

Also, some of my old commit messages are terrible. "New update" tells me basically nothing when I go back to find a change.

## What next?

I want to add more projects, especially robot stuff. I'll write about them here when I have something to show.

The code is on [GitHub](https://github.com/yigit-kilicaslandev/websiteing) if you want to look around. I'm still changing things, so it'll probably look different again later.
