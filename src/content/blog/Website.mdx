# How I made my website

I'm 10 and I wanted my own portfolio website to put my projects on. I started it in 2026. There weren't many projects to add yet, but now the website is one of those projects lol.

I didn't make the whole thing from scratch. I used a template and forked [Starfolio](https://github.com/webrating/starfolio) on GitHub, then started changing the example stuff to my own information. The design was already there, which helped a lot while I was making it.

## What I changed

There's a file called `resume.tsx` with my name, schools, projects, and a lot of other information in it. Most of my changes started there. I added my Lego sumo robot, the competitions I've joined, and this website.

Then I added some travel pictures that I found and the icons in the skills section. I ended up removing some skills too. Just because the website uses React and TypeScript doesn't mean I know them well enough to put them on my list.

I use AI to help with the code. I'm still learning, and being able to change my information in a file isn't the same as knowing how every part of the website works.

## A few things went wrong

The X icon broke because the icon library didn't export the one we were trying to use. The dark mode button also got stuck showing the sun, even in light mode. The moon icon was there, just hidden all the time for some reason.

The Dubai and Santorini photos were too big for Cloudflare. It has a 25 MiB limit for each file, and both were over it, so the build failed. We replaced them with smaller photos. I wouldn't have guessed two pictures could stop the whole build.

The travel photos are from other photographers, so there's a credits section under the gallery now. Some of the licenses require it.

Also, some of my old commit messages were TERRIBLE. "New update" tells me basically nothing when I go back to find a change.

## What next?

I want to add more projects, especially robot stuff. I'm going to write about them here when I have something else to show 😭.
